# Penline (เป็นไลน์ไหม)

โปรแกรมวาดเวกเตอร์แบบเรียบง่าย เบา และเร็ว ได้แรงบันดาลใจจาก Inkscape แต่ตัดฟีเจอร์ระดับมืออาชีพออก ออกแบบแบบ mobile-first และติดตั้งเป็นแอป (PWA) ได้

## ฟีเจอร์

- เครื่องมือ: เลือก/ย้าย, สี่เหลี่ยม, วงรี, เส้นตรง, ปากกาเส้นโค้ง (Bezier), ดินสอ, ข้อความ
- ปากกาเส้นโค้ง: แตะวางจุด ลากเพื่อดึงก้านดัดโค้ง แตะจุดแรกเพื่อปิดรูป แก้จุดและก้านภายหลังได้ แตะจุดสองครั้งเพื่อสลับมุม/โค้ง
- ย่อขยายด้วยจุดจับ, ทำสำเนา, จัดลำดับชั้น, ลบ, Undo/Redo
- เลเยอร์: เพิ่ม, เปลี่ยนชื่อ, ซ่อน/แสดง, ล็อก, เลื่อนขึ้นลง, ลบ
- จานสีกำหนดเองได้: เพิ่ม/ลบสี, วางรหัสสีหลายสีพร้อมกัน, จานสำเร็จรูป
- หน้าจอเรียบง่าย: วงกลมสี (ซ้ายบน), เลเยอร์ (ขวาบน), กระบอกเครื่องมือ (ซ้ายล่าง), ซูม (ขวาล่าง)
- สีพื้น สีเส้น และความหนาเส้น
- ใช้สองนิ้วซูมและเลื่อนจอบนมือถือ, ล้อเมาส์ซูมบนเดสก์ท็อป
- บันทึกอัตโนมัติในเบราว์เซอร์, ส่งออก PNG และ SVG
- ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## ไม่ใช้ build step

เป็นไฟล์ HTML/JS/CSS ล้วน ไม่มี dependency

```
index.html             แอปทั้งหมด
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับออฟไลน์
icon*.png, icon.svg    ไอคอน
```

## รันในเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## Deploy ด้วย GitHub Pages

repo นี้มี workflow ที่ `.github/workflows/pages.yml` อยู่แล้ว

1. ไปที่ **Settings → Pages**
2. ตั้ง **Source** เป็น **GitHub Actions**
3. push เข้า `main` แล้วแอปจะขึ้นที่ `https://larbkoystudio.github.io/pen-line-mai/`

## ติดตั้งบนมือถือ

- **Android / Chrome:** เมนู ⋮ → ติดตั้งแอป
- **iPhone / Safari:** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

## คีย์ลัด (เดสก์ท็อป)

| คีย์ | การทำงาน |
|---|---|
| V R E L B P T | เลือก / สี่เหลี่ยม / วงรี / เส้น / ปากกาเส้นโค้ง / ดินสอ / ข้อความ |
| Enter / Esc | จบเส้นที่กำลังวาดด้วยปากกา |
| Alt + ลากก้าน | ดัดก้านข้างเดียว (มุมแหลม) |
| Shift ขณะวาด | สี่เหลี่ยมจัตุรัส, วงกลม, เส้นทุก 45° |
| Ctrl+Z / Ctrl+Shift+Z | ย้อนกลับ / ทำซ้ำ |
| Ctrl+D | ทำสำเนา |
| Delete | ลบ |
| ลูกศร (+Shift) | ขยับ 1 (10) หน่วย |
| Space + ลาก | เลื่อนจอ |
